# كاش الترجمة

`content_hash` هو SHA-256 لمحتوى الملف، وليس اسمه. `fingerprint` يجمع البصمة واللغات والمحرك وإصداره ومحرك PDF وإصداره ونمط الإخراج وOCR. القيد الفريد في `translation_jobs` يمنع التكرار المتزامن. النتائج المكتملة في R2 سياسة احتفاظها `PERSISTENT` افتراضيًا؛ الملفات المؤقتة فقط تنظفها الخدمة.

لا يُعرض صاحب الترجمة. لا يسمح الكاش بتجاوز صلاحيات المادة الأصلية، ولا ينشئ نسخة لكل باحث.
