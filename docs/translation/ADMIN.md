# لوحة الإدارة

تحتوي لوحة `/admin/translation` على مؤشرات `translation_usage` و`translation_events` (cache hit/miss، الوظائف الجارية والفاشلة، الصفحات وOCR)، ونموذج لترجمة ملف PDF واحد أو عدة ملفات بعد اختيار المصدر والهدف والصيغة وOCR. تعرض قائمة الوظائف حالة كل كتاب ونسبته ومراحل المعالجة، ويمكن حذف وظيفة وملفها الناتج أو تنظيف الوظائف المكتملة/الفاشلة القديمة والكاش بعد عدد أيام يحدده المدير. كل عمليات الحذف تُسجل في `audit_log` ولا تمس ملفات الأصل.
