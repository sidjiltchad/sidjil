## خامسًا: القرار المعماري — حُسم (2026-10-01)

المواصفات (§4) كانت تنص على **Astro + TypeScript + Tailwind + Hono + Zod + Cloudflare Access**، بينما بُنيت المنصة **بلا أي إطار** (HTML/CSS/JS خالص + PBKDF2) التزامًا بتعليم يعقوب السابق «بلا أطر خارجية».

**القرار (اعتمد يعقوب نهائيًا 2026-10-01):** إبقاء البناء الحالي — يعمل بالكامل، خفيف، بلا اعتماديات، سهل الصيانة. أصبح البند §4 «اقتراحًا تقنيًا غير ملزم». التفاصيل: `docs/adr/001-vanilla-stack.md`.

نقاط إضافية:
- PDF.js تُستخدم كمكتبة وظيفية فقط (لا إطار) — لا تخرق القرار.
- الجدول في «ثانيًا» أعلاه: كل ما هو «منفذ بصيغة مختلفة» مقبول ضمن هذا القرار.
