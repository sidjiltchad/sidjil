## 3) النسخ الاحتياطي

- المسار: `backups/2026-10-01/` — `d1-sidjil-prod.json` + `r2-sidjil-assets-inventory.json` + `manifest.json` (4 ملفات، SHA-256 موثقة)
- ملاحظة: النسخة منطقية بصيغة JSON وليست SQL export أصليًا — يُستكمل لاحقًا إن لزم حرفيًا.

## 4) إجراءات أمنية معلقة (على مالك المشروع)

1. **تدوير Cloudflare API Token** — الرمز الحالي ظهر صراحةً في سجل المحادثة ويُعتبر مكشوفًا بالكامل: Revoke ثم إنشاء رمز جديد بتخزين آمن.
2. **تدوير كلمة سر المدير** — ظهرت في السجلات: تغييرها عبر قناة آمنة ثم تحديث `ADMIN_PASSWORD_HASH`.
3. بعد التدوير: أي عملية Cloudflare لاحقة تتطلب الاعتماد الجديد عبر قناة آمنة.

## 5) خارج النطاق حاليًا

- ربط دومين `sidjil.org` — يتطلب إذنًا صريحًا جديدًا.
- `OCR_ENDPOINT` / `OCR_API_KEY` — لا تُضبط (لا مزود إنتاج فعلي).
- اختبار هاتف حقيقي (Android) — لم يُجرَ؛ فحص التجاوب تم عبر الكود فقط.

## 6) القرار

**الموقع منشور ويعمل** على العنوان المؤقت. **الجاهزية النهائية تُعلن بعد** تنفيذ البندين الأمنيين في §4.
