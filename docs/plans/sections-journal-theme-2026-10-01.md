# خطة التعديل: أقسام سِجِل + مجلة سِجِل + حسابات الباحثين + إعلانات + الثيم

تاريخ الخطة: 2026-10-01 — بطلب يعقوب قبل استيراد ملفات مجلد Tchad.
آخر تحديث: 2026-10-01 — أُضيف: قسم ديني، تعدد الأقسام للمادة الواحدة،
حسابات الباحثين ودورة المراجعة، الإعلانات الإدارية، مشاركة كل المواد.
الحالة: اعتمدها يعقوب 2026-10-01 — التنفيذ جارٍ (المراحل 1–4 محليًا).
المرحلة 5 (النشر والاستيراد) تنتظر كلمة مرور الإدارة الجديدة.

## الرؤية

تحويل سِجِل من «أرشيف تاريخي» إلى **منصة ثقافية تشادية متعددة الأقسام**
يديرها فريق: مديرون وباحثون مساهمون، مع مجلة دورية وإعلانات ومشاركة اجتماعية.

---

## 1) أقسام سِجِل السبعة

### التصميم
- الأقسام تُبنى على البنية الموجودة: **الأقسام = مجموعات (collections) من نوع خاص**.
- Migration `0004`: إضافة عمود `kind` لجدول `collections` بالقيمتين
  `section` و`collection` (الافتراضي `collection`).
- **المادة الواحدة تنتمي لأكثر من قسم** (many-to-many عبر `material_collections`
  الموجود أصلًا) — مثال: كتاب عن الشعر الصوفي يُنسب لـ«سجل أدبي» و«سجل ديني» معًا.
- الأقسام السبعة عند الإطلاق:
  1. سِجِل تاريخي — يستوعب كل رصيد الأرشيف الحالي + استيراد Tchad
  2. سِجِل أدبي — للتراث الأدبي التشادي (عربي/فرنسي) مخطوطًا ومطبوعًا
  3. سِجِل شعري
  4. سِجِل سياسي
  5. سِجِل لغوي
  6. سِجِل معاصر
  7. سِجِل ديني
- الأقسام 2–7 تُملأ مستقبلًا برفع موادها.

### الواجهات
- الرئيسية: شريط «أقسام سِجِل» بارز (7 بطاقات) أعلى المجموعات الموضوعية.
- صفحة `/sections` وصفحة القسم `/section/{id}` (ترويسة القسم + مواده +
  مجموعاته الفرعية).
- صفحة المادة: رقائق (chips) الأقسام التي تنتمي إليها.
- التنقل العلوي: «الأقسام» بجانب «المجموعات».
- i18n: مفاتيح عربية/فرنسية جديدة.

### لوحة الإدارة
- عند إنشاء/تعديل مادة: **اختيار متعدد للأقسام** (checkboxes) بدل الاختيار الواحد.
- إدارة المجموعات: تمييز القسم عن المجموعة الموضوعية (kind) + ترتيب العرض.

## 2) مجلة سِجِل (Journal)

### الفكرة
مجلة دورية يصدرها باحثون في التاريخ والسياسة والأدب وغيرها — كل عدد ملف PDF
يُعرض ويُحمّل ويُشارك رابطه على شبكات التواصل.

### التصميم
- نوع مادة جديد: `journal` — رمز الأرشيف `JRN` (مثال: `ARC-TD-JRN-000001`).
- نوع مادة جديد: `article` — رمز `ART` — لمقالات المجلة والمساهمات المُستكتبة.
- الأكواد والمجلدات تُضاف في `TYPE_CODES`/`TYPE_DIRS` (تعديل برمجي، لا هجرة).
- الحقول المعاد استعمالها: `title_ar` («مجلة سِجِل — العدد الأول»)، `description`،
  `year`، الملف PDF (مسموح أصلًا).
- ربط المقالات بالأعداد عبر علاقات المواد الموجودة (`material_relations`).

### الواجهات العامة
- `/journal`: قائمة الأعداد (الأحدث أولًا) — بطاقة لكل عدد: الغلاف، العنوان،
  التاريخ، زرّا عرض وتحميل.
- `/journal/{ark}`: عارض PDF المدمج + تحميل + **أزرار المشاركة**.
- وسوم Open Graph لمعاينة جميلة عند مشاركة الرابط.

## 3) حسابات الباحثين ودورة المراجعة

### الفكرة
المدير يفتح حسابات دخول للباحثين بصلاحيات نشر محدودة: يكتبون ويرفعون،
لكن لا شيء يُنشر إلا بعد مراجعة الإدارة واعتمادها.

### الصلاحيات
- Migration `0004`: عمود `role` في `admin_users` بالقيمتين `admin` و`researcher`.
- **الباحث** يستطيع: إنشاء مواد (كل الأنواع بما فيها `article`)، تعديل مواده
  ما دامت غير منشورة، رفع صور وملفات لمواده، عرض سجل منشوراته وحالاتها،
  إرسال المادة للمراجعة، الكتابة للمجلة عند الاستكتاب من نفس الواجهة.
- **الباحث لا يستطيع**: النشر المباشر، تعديل مواد غيره، حذف مواد منشورة،
  إدارة المستخدمين أو التصنيفات أو الإعلانات أو إعدادات الموقع.
- **المدير**: كل شيء + طابور المراجعة + إدارة حسابات الباحثين.

### دورة النشر
- Migration `0004`: حالة جديدة `in_review` في `publish_status`
  (draft → in_review → published)، وعمود `review_note` لملاحظة الإدارة.
- الباحث ينشئ مسودة → «إرسال للمراجعة» → تظهر في طابور الإدارة →
  المدير يعتمد (published) أو يعيدها (draft + ملاحظة سبب الإعادة).
- سجل التدقيق (audit) يسجّل كل انتقال كما يسجّل العمليات الإدارية اليوم.

### واجهة الباحث (خفيفة)
- لوحة مبسطة منفصلة عن لوحة الإدارة الكاملة: «منشوراتي» (جدول بالحالة:
  مسودة/قيد المراجعة/منشور/أُعيد)، «مادة جديدة»، «مقال للمجلة».
- نموذج إدخال مختصر: العنوان، القسم (متعدد)، الوصف، السنة، الملفات —
  دون خيارات الإدارة المتقدمة.
- تنبيه مرئي عند إعادة مادة مع ملاحظة المدير.

### مساهمات المجلة
- «مقال للمجلة» = مادة نوعها `article` تُنشأ من واجهة الباحث وتُرسل للمراجعة.
- عند الاعتماد يرفقها المدير بعدد المجلة (علاقة مادة↔مادة) أو ينشرها مستقلة.

## 4) الإعلانات الإدارية

- Migration `0004`: جدول `announcements`:
  `id, title_ar, title_fr, body_ar, body_fr, link_url, active, sort_order,
  starts_at, ends_at, created_at`.
- الصفحة الرئيسية للزوار: شريط/قسم الإعلانات يعرض النشطة منها ضمن تاريخها،
  قابلة للإغلاق من الزائر (تُحفظ في localStorage).
- لوحة الإدارة: قسم «إعلانات» — إنشاء/تعديل/تفعيل/إيقاف/جدولة.

---

## 5) مشاركة المواد على شبكات التواصل

- مكوّن مشاركة موحّد يُستعمل في صفحة المادة وصفحة العدد:
  واتساب، تيليغرام، X، فيسبوك، نسخ الرابط (share-intent — لا مفاتيح API).
- وسوم Open Graph على صفحات المواد والأعداد (العنوان، الوصف، صورة المادة أو الشعار).

---

## 6) الثيم الليلي/النهاري

- `style.css` يستعمل CSS variables أصلًا — إضافة كتلة `[data-theme="dark"]`
  تُعيد تعريف المتغيرات دون المساس بالبنية.
- زر تبديل في الترويسة (أيقونة شمس/قمر SVG)، يُحفظ في `localStorage`
  (`sidjil-theme`)، والافتراضي من `prefers-color-scheme`.
- سكربت مبكر في `<head>` يضبط `data-theme` قبل أول رسم (منع الوميض).
- يُطبق على الموقع العام + لوحة الإدارة + واجهة الباحث.
- التحقق من تباين الشعار في الوضعين.

### سجل الاختبار المحلي (2026-10-01)
- الهجرة `0004` طُبقت على D1 المحلية بنجاح (16 أمرًا)؛ الأقسام السبعة موجودة (ids 3–9).
- دورة الباحث كاملة: إنشاء (فرض مسودة رغم طلب النشر) → إرسال → قفل `in_review` (إصلاح ثغرة كانت تسمح بالتعديل أثناء المراجعة) → رفض بملاحظة → تعديل → إعادة إرسال → اعتماد ونشر → حظر حذف المنشور (403).
- حظر النشر المباشر على الباحث (403)، حظر `/api/v1/admin/users` (403)، فلترة قائمة المواد لمواد الباحث فقط، تحويل `/admin*` → `/researcher` للباحث.
- إدارة المستخدمين: إنشاء + تحقق صيغة الاسم/طول الكلمة + إيقاف/تفعيل (إبطال الجلسات) + منع تغيير الدور الذاتي + رفض دخول الموقوف.
- رفع PDF وحذفه عبر الباحث؛ الرفع أثناء `in_review` محظور (403)؛ رفض نوع ملف غير مسموح.
- الصفحات العامة: `/` (إعلان قابل للإغلاق + شريط الأقسام + زر الثيم) `/sections` `/section/3` (مادة بقسمين) `/journal` `/journal/{ark}` (مشاركة + `og:url` مطلقة) `/document/{ark}` (رقائق الأقسام + مشاركة + `og:image` مطلقة) `/collection/3` → 302 إلى `/section/3`.
- عدم كسر: `/` `/search` `/api/v1/search` `/categories` `/admin` `/admin/materials` — كلها 200؛ مفاتيح i18n متوازنة ar/fr.
- لم يُختبر بصريًا: لقطات الوضعين الليلي/النهاري (لا متصفح headless متاح في بيئة التطوير).
- بيانات الاختبار حُذفت من D1 المحلية (عادت 9 مواد + حساب `admin` الأصلي).

### اعتبارات تقنية ثابتة
- Migration `0004` واحدة تجمع كل تغييرات DDL، تُطبق محليًا أولًا ثم على
  D1 الإنتاج قبل إعادة النشر.
- لا تُمس المواد التسع المنشورة ولا أرقام `ARC-TD-*`.
- حد الرفع 100MB وأنواع الملفات المسموحة تبقى كما هي.
- الاختبار بعد كل مرحلة: عناوين ar/fr، البحث، صفحة مادة، API،
  دورة الباحث كاملة (إنشاء → مراجعة → اعتماد/إعادة)، لقطات للوضعين.
