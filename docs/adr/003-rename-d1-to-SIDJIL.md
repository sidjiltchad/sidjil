# ADR-003: تسمية قاعدة D1 باسم SIDJIL

**التاريخ:** 2026-10-01
**الحالة:** معتمد بناءً على طلب مالك المشروع

## القرار

تسمية قاعدة D1 الإنتاجية `SIDJIL` وربط Worker بها عبر `DB`. اسم القاعدة السابق `sidjil-prod` يبقى في سجلات النشر والنسخ التاريخية فقط.

## التنفيذ

لا يتيح Cloudflare تغيير اسم قاعدة D1 القائمة في مكانها. أُنشئت قاعدة جديدة باسم `SIDJIL` في منطقة ENAM، وطُبقت عليها الهجرات `0001` إلى `0004`، ونُقلت بيانات الجداول وفهرس البحث FTS5. طابقت أعداد السجلات في الجداول الـ24، ولم يظهر خطأ في `PRAGMA foreign_key_check`. بقيت القاعدة القديمة دون حذف لتيسير الرجوع عند الحاجة.

حدثت مراجع الاسم في `wrangler.toml` وأوامر المشروع وتوثيق التشغيل. لم تُغيّر معرفات الكوكيز القديمة، لأنها ليست اسم قاعدة البيانات وتغييرها يقطع جلسات المستخدمين وتفضيلات اللغة.
