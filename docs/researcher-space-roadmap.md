# خطة تطوير مساحة الباحث

هذه الوثيقة هي المرجع التنفيذي لمساحة الباحث في `app.sidjil.org`.

## ما نُفذ

- إضافة سجل `material_workflow_events` لتوثيق انتقالات المواد.
- ترحيل الاعتمادات التاريخية من `audit_log` إلى سجل سير العمل.
- إضافة إشعارات إرسال المادة والاعتماد والرفض وطلب التعديل.
- فصل قرار «طلب التعديل» عن «الرفض».
- عرض المواد المعتمدة في موجز «اعتمادات الإدارة» دون ربطها بمالك المادة فقط.
- فرض Super Admin على تعديل الأدوار والحسابات الحساسة وإعادة كلمات المرور.
- فرض كلمة مرور جديدة بعد إعادة تعيينها.
- إضافة آخر دخول والجلسات النشطة وإبطال الجلسات الأخرى.
- إضافة إعداد ظهور الملف في دليل الباحثين.
- إصلاح صور الباحثين غير الموثقين أو الحسابات التي لا تملك ملف R2.
- تحويل نماذج النقاش إلى Event Delegation حتى تعمل بعد البحث والتحميل التلقائي.
- إضافة CSRF لمسارات الترجمة والمتابعة، وتحديد معدل طلبات الترجمة.
- تقليل القراءة الأولية للموجز بدل تحميل 500 مادة دائمًا.
- إضافة Focus restoration وخصائص وصول للنوافذ المنبثقة.

## المراحل التالية

1. تحويل كل موجز إلى Cursor Pagination وإزالة حدود `OFFSET` الثابتة.
2. بناء فهرس ملفات أساسية لكل مادة للغلاف وPDF.
3. استكمال نصوص الوثائق وتدقيق جودة الكتب والملفات.
4. إعادة بناء الترجمة إلى وظائف صفحات قابلة للإيقاف والاستئناف.
5. إضافة الإعجابات والحفظ والإبلاغ والإشارات والوسوم.
6. إضافة ترقيم كامل للملفات والنقاشات والردود والملفات الشخصية.
7. إضافة لوحة مؤشرات D1 والأخطاء وأداء الترجمة.
8. إجراء اختبار وصول شامل للهاتف ولوحة المفاتيح وقارئات الشاشة.

## قاعدة الإطلاق

لا تُفعّل أي مرحلة جديدة في الإنتاج قبل نجاح فحص الصياغة، وفحص `wrangler deploy --dry-run`، واختبار API للزائر والباحث الموثق والمدير وSuper Admin، وفحص D1 Rows Read.
