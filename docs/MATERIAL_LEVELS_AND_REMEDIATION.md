# نموذج مواد سِجِل وخطة الإصلاح

## التصنيف الإلزامي

يحتفظ الحقل `materials.type` بالرمز الأرشيفي، مثل `DOC` و`BOK` و`IMG`. أما
`materials.material_level` فهو التصنيف التحريري الذي يحدد ما تعتبره المنصة مادة
وما يلزم لاكتمالها:

| المستوى | المادة الأساسية | متطلبات العرض |
| --- | --- | --- |
| `archival_image` | الصورة أو الخريطة الأصلية | صورة مرتبطة + وصف موثق |
| `archival_text` | التفريغ النصي | نص كامل منسق + مصدره، بلا ملف PDF للمادة؛ لا يعرض Word للتنزيل إذا كان النص موثقًا |
| `archival_book_original` | كتاب أو رسالة أو ملف PDF أصيل | PDF أصلي + غلاف + وصف توثيقي |
| `archival_book_unavailable` | سجل كتاب غير متاح | عنوان + غلاف + وصف، دون اختلاق PDF |
| `chadian_publication` | كتاب أو مؤلف تشادي | غلاف ووصف، وPDF فقط عند توفره فعلًا |

طبقت الهجرة `0044_material_levels.sql` التصنيف على المواد الحالية باستخدام
نوع المادة، القسم المرتبط، ووجود PDF فعلي في جدول `files`. يمكن للإدارة تعديل
المستوى يدويًا عند وجود حالة استثنائية.

## قواعد الإدخال

- يختار المدير أو الباحث مستوى المادة عند إنشاء المسودة.
- الكتاب الذي يرفع له PDF ينتقل تلقائيًا من «غير متاح» إلى «أصيل متاح»، مع بقاء
  مستوى المؤلف التشادي محفوظًا إذا اختارته الإدارة.
- لا يطلب النظام PDF للمؤلف التشادي أو الكتاب غير المتاح.
- لا يطلب غلافًا للصورة، بل يطلب الصورة الأصلية.
- لا يطلب PDF للمادة النصية، بل يطلب التفريغ النصي داخل المنصة.

## خطة الإصلاح المرتبطة

1. **البحث:** مسار LIKE مطبع للعربية مع ردود API منظمة واختبارات عربية وفرنسية وإنجليزية.
2. **الصلاحيات:** لا يتجاوز نشر الملفات إلا المدير أو Super Admin؛ الباحث يرى المنشور ومواده المسموح بها فقط.
3. **اكتمال المحتوى:** ترتيب طابور الإصلاح حسب PDF، التفريغ، الغلاف، ثم البيانات الوصفية.
4. **الترجمة:** Jobs قابلة للاستئناف، حفظ صفحة بصفحة، Retry، كشف الوظائف العالقة، وDead Letter Queue.
5. **العزل:** مسارات `app.sidjil.org` للباحثين فقط؛ صفحات الموقع العام تفتح من النطاق الرسمي صراحة.
6. **صحة المحتوى:** حساب النقص من `material_level` بدل التخمين من `type`، مع فحص R2 فعلي.

قاعدة ثابتة: وجود ملف PDF فعلي ينقل المادة خارج `archival_text`. تُصنّف افتراضيًا كـ`archival_book_original`، ويمكن اختيار `chadian_publication` صراحة للمؤلفات التشادية قبل الرفع أو من نموذج التعديل.
7. **PWA:** Service Worker واحد متسق مع Manifest التطبيق ومحتوى الباحثين، دون تخزين الصفحات الخاصة.
8. **الأمن:** CSP وHSTS و`nosniff` وReferrer Policy وPermissions Policy، مع مراجعة CSP الخاصة بـPDF.js.
9. **الاختبارات:** اختبارات مسارات، صلاحيات، بحث عربي، رفع، نشر، عارض، وترجمة في CI قبل النشر.
10. **المجتمع:** إدخال بيانات تجريبية، تفاعلات، متابعة، تبليغات وإشعارات للتحقق من الدورة كاملة.

## معايير القبول قبل اعتبار النموذج مكتملًا

- لا توجد مادة منشورة بلا مستوى.
- كل صورة أرشيفية لها صورة ووصف.
- كل مادة أرشيفية نصية لها نص موثق أو تكون في طابور الإصلاح.
- كل كتاب أصيل متاح له PDF وغلاف.
- الكتاب غير المتاح لا يظهر له زر تنزيل PDF.
- لا يستطيع الباحث فتح ملف غير منشور.
- البحث العربي يعيد `200` ونتائج صحيحة.
- لا يوجد رابط غير مقصود من تطبيق الباحثين إلى واجهة الموقع العام.
- لا توجد وظيفة ترجمة عالقة دون Retry أو سبب واضح.
