# حزمة «مجلس سِجِل» — تطبيق الويب التقدمي للنقاشات العلمية

## ما في هذه الحزمة

تطبيق الويب التقدمي (PWA) لمنصة النقاشات — شبكة اجتماعية علمية عربية خالصة:

- **الأدوار**: زائر (بلا حساب — يتفاعل فقط) · باحث (بحساب، لا ينشر حتى توثيقه) ·
  باحث موثّق ✓ (وحده يخوض النقاش) · الإدارة (توثّق الباحثين وتشرف على النقاشات)
- **النقاشات**: تعليق / مراجعة / نقد / نقد فكرة / نقد نص (مع اقتباس النص المنتقد ورقم الصفحة)
- **التفاعلات بلا حساب**: إعجاب، دعم، مفيد، أعارض — بحدّ معدل لكل IP
- **الصفحات**: `/discussions` (بطاقات + فلترة) · `/discussion/:id` (مع OG للمشاركة) ·
  قسم النقاشات في صفحة كل مادة · `/researcher/register` (تسجيل الباحثين)
- **مساحة الباحث**: صفحة «نقاشاتي» + منشئ نقاش جديد (يرتبط بمادة اختياريًا)
- **الإدارة**: زر «توثيق» في صفحة المستخدمين + صفحة «النقاشات» للإخفاء/الإظهار والحذف
- **PWA**: `manifest.json` + Service Worker (أوفلاين للقراءة) + شريط سفلي في وضع التطبيق

## خطوات الدمج والنشر

1. انسخ محتويات الحزمة فوق نسختك من المستودع (استبدال ملفات).
2. ادفع إلى `main` — النشر تلقائي عبر Cloudflare.
3. طبّق الهجرة على قاعدة الإنتاج (مباشرة بـ SQL لأن `migrations apply` مرفوض برمز 7403):

```
npx wrangler d1 execute SIDJIL --remote --file=migrations/0008_discussions.sql
```

4. تحقق: افتح `/discussions` — يجب أن ترى صفحة «مجلس سِجِل».

## ملاحظات

- الباحثون الحاليون (المنشأون يدويًا) صاروا موثّقين تلقائيًا في الهجرة.
- التفاعلات المجهولة تُمنع من التكرار بمفتاح `(النقاش، الفاعل)` + حد 30/دقيقة لكل IP.
- الـ Service Worker لا يخزّن الـ API مؤقتًا — النقاشات تظهر تلقائيًا دائمًا.

## ما اختُبر محليًا

دورة كاملة: تسجيل باحث → حظر النشر قبل التوثيق (403) → توثيق → نشر نقاش →
رد → تفاعل زائر (إعجاب ثم تغييره لدعم) → إخفاء/إظهار من الإدارة →
التحقق من الصفحات بالعربية والفرنسية. كلها ناجحة.
