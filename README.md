# سِجِل — SIDJIL

> الاسم السابق للمشروع: أرشيفنا / Archifouna (أُعيدت التسمية في 2026-10-01؛ انظر `docs/adr/002-rename-archifouna-to-sidjil.md`).

**ذاكرة تشاد بين يدي الباحث**

منصة أرشيف رقمية للوثائق والصور والمصادر المتعلقة بتاريخ تشاد، مبنية على
Cloudflare Workers + D1 + R2، **دون أي إطار عمل خارجي** — HTML/CSS/JS خالص.

## المبادئ المنهجية (ملزمة في كل المحتوى)

- **الأصل لا يُمسّ ولا يُستبدل** — أي معالجة (ترميم/تحسين/تلوين) نسخة مستقلة معلَّمة.
- التفريغ والترجمة والترميم والتحسين والتلوين **طبقات مستقلة** معلَّمة بوضوح.
- **المصدر مقدَّم على الادعاء** — كل معلومة موثقة برقم أرشيفي ثابت.
- التفريق الصريح بين: المؤكد / المرجَّح / التقديري / المجهول.
- التلوين **تقديري** وليس دليلًا على الألوان الأصلية.

## التشغيل المحلي

```bash
npm install
npx wrangler d1 execute archifouna-db --local --file=migrations/0001_init.sql
npx wrangler dev --port 8787
```

زرع حساب المدير (كلمة مرور تجريبية — غيّرها للإنتاج):

```bash
node scripts/hash-password.js 'كلمة-مرور-قوية'
# ضع الناتج في .dev.vars باسم ADMIN_PASSWORD_HASH
```

تجهيز بيانات العرض (وثائق GG AEF 5D 269 + صور أبشة الحقيقية):

```bash
SEED_ADMIN_PASSWORD='<كلمة-المرور-التي-سجلتها-في-.dev.vars>' node scripts/seed-demo.mjs
```

ثم افتح `http://127.0.0.1:8787/` — ولوحة الإدارة `http://127.0.0.1:8787/admin`.

## النشر إلى Cloudflare

راجع `docs/دليل-التشغيل-والنشر.md` — الخطوات: إنشاء D1 وR2 للإنتاج،
تطبيق الهجرة، ضبط `ADMIN_PASSWORD_HASH` كـ secret، ثم `wrangler deploy`.

## البحث

- عربي/فرنسي مع تطبيع (إأآ→ا، ة→ه، إزالة التشكيل، إزالة الـ stop words الفرنسية).
- البحث العربي يجد الوثائق الفرنسية والعكس (فهرسة متقاطعة للترجمات والتفريغات).
- مثال: «التعليم العربي في أبشة» يسترجع وثائق GG AEF 5D 269 الفرنسية.
