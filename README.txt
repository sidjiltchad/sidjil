سِجِل — حزمة التحديث الشامل للتصميم + الأوصاف الفرنسية
==================================================

المحتوى:
- تصميم جديد كليًا: خطوط عربية محلية (Noto Kufi Arabic للعناوين + IBM Plex Sans Arabic للنصوص)
  بدل خطوط Google الخارجية — أسرع ولا يعتمد على إنترنت خارجي.
- تلميع الواجهة العامة: سلم طباعي، بطاقات وأزرار عصرية، انتقالات ناعمة، تركيز مرئي،
  قائمة همبرغر محسّنة للهاتف، وضع ليلي محسّن، دعم تقليل الحركة.
- واجهة إدارة جديدة كليًا: شريط علوي + شريط جانبي منزلق للهاتف، جداول برأس ثابت
  وتمرير أفقي، نماذج وشارات وأزرار موحدة، صفحة دخول بتصميم جديد.
- إصلاح الأوصاف الفرنسية للأقسام (description_fr).

خطوات التركيب (في D:\sidjil-full-project):
1. فكّ الضغط في جذر المستودع مع الاستبدال (البنية الداخلية جاهزة: public/ و src/ و migrations/).
2. git add -A && git commit -m "تحديث شامل للتصميم + الأوصاف الفرنسية" && git push
   (النشر على Cloudflare تلقائي).
3. إضافة عمود الوصف الفرنسي (تخطَّ إن نفذتها سابقًا):
   npx wrangler d1 execute SIDJIL --remote --command="ALTER TABLE collections ADD COLUMN description_fr TEXT;"
4. إدخال الترجمات الفرنسية (من مجلد الحزمة):
   npx wrangler d1 execute SIDJIL --remote --file=sidjil-desc-fr.sql
5. تحقق:
   - https://sidjil.org/ (شكل جديد + خطوط جديدة)
   - https://sidjil.org/sections?lang=fr (أوصاف فرنسية)
   - https://sidjil.org/admin (تصميم الإدارة الجديد)
   - من الهاتف: القائمة الجانبية للإدارة بزر الهمبرغر
