# حالة ترحيلات قاعدة بيانات سِجِل

## `0035_file_translations.sql.retired`

هذا الملف متقاعد ولا يدخل في قائمة الترحيلات التي يشغلها Wrangler. كان يكرر
إنشاء `file_translations` و`translation_requests` ويضيف `files.lang`، ثم ظهر في
الإنتاج كترحيل معلّق رغم أن الجداول والبنية أصبحت موجودة عبر الترحيل اللاحق
`0047_manual_file_translations.sql` وترحيلات التوافق التالية.

لا يُعاد تشغيل الملف ولا تُعدّل يدويًا سجلات `d1_migrations`. قبل أي ترحيل
مستقبلي يجب أخذ نسخة احتياطية ومقارنة مخطط الإنتاج مع ملفات الترحيل الحالية.
